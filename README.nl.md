# JSON Harbor

Formatteer, controleer en verklein JSON in een overzichtelijke werkruimte. JSON Harbor draait volledig in je browser, zodat privégegevens je apparaat niet verlaten.

**Talen:** [English](README.md) | [Nederlands](README.nl.md)

## Functies

- Geldige JSON netjes formatteren of verkleinen
- Duidelijke parsefouten van de JSON-parser in je browser
- Resultaten kopiëren of downloaden als `.json`
- Voorbeeldpayload, tekentelling en resetknop
- Geen dependencies, accounts, tracking of netwerkverzoeken

## Gebruiken

Open `index.html` in een browser. Plak JSON en kies **JSON formatteren** of **Verkleinen**. De app werkt offline.

## Publiceren met GitHub Pages

Push naar de branch `main`. De meegeleverde GitHub Actions-workflow publiceert de site naar GitHub Pages. Stel bij de repository-instellingen zo nodig **Pages > Build and deployment > Source** in op **GitHub Actions**.

## Privacy

Alle parsing en opmaak gebeurt lokaal in de pagina. Een browsertool vervangt niet de regels voor gegevensverwerking van je organisatie.
