# JSON Harbor

Format, validate, and minify JSON in a clean side-by-side workspace. JSON Harbor runs entirely in your browser, so private payloads never leave your device.

**Languages:** [English](README.md) | [Nederlands](README.nl.md)

## Features

- Pretty-print and minify valid JSON
- Clear parse errors from the browser's JSON parser
- Copy results or download a `.json` file
- Example payload, character counts, and one-click reset
- No dependencies, accounts, tracking, or network requests

## Use it

Open `index.html` in a browser. Paste JSON and choose **Format JSON** or **Minify**. The app works offline.

## Publish with GitHub Pages

Push to the `main` branch. The included GitHub Actions workflow publishes the site to GitHub Pages. In repository settings, set **Pages > Build and deployment > Source** to **GitHub Actions** if it is not selected automatically.

## Privacy

All parsing and formatting runs locally in the page. Do not treat a browser-based tool as a substitute for your organization's data-handling requirements.
